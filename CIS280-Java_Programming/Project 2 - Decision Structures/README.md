
# Project 2: Number Range Validator

A Java console application that demonstrates decision-making structures (`if`/`else`) and input-validation loops. The program repeatedly prompts the user for an integer until an acceptable value within the target range is provided.

---

## Features

- **Input Validation Loop**: Continuously prompts the user until a valid integer is supplied.
- **Range Checking**: Validates whether the entered number falls within the specified bounds (default: 1–50).
- **Conditional Feedback**: Notifies the user whether an invalid input is too low or too high.
