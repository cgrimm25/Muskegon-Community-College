Topic 5: Add animation

Project Overview: I developed a physics-based animation loop that spawns colored balls that drop via simulated gravity, bounce off the canvas walls, and gradually slow down due to a friction multiplier. This demonstrates the topic of canvas animation by using setTimeout() to recursively trigger a frame-drawing function, clearing the canvas completely before redrawing the balls in their new coordinate positions. I changed the visual styling to match my project theme and learned that true canvas animation does not involve moving objects, but rather rapidly erasing and redrawing the entire frame to simulate motion based on state variables.
