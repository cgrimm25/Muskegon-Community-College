Topic 4: Make a Shape Interactive

Project Overview: I built an application where clicking a button spawns randomly sized circles, and clicking directly on the canvas highlights a specific circle with a thick white border. This demonstrates shape interactivity by calculating the exact mathematical distance between the user's raw mouse click coordinates and the center point of each generated circle using the Pythagorean theorem. I changed the textbook's default colors to match my dark-slate theme and learned that storing shape data in a JavaScript array is strictly required for interactivity, as the canvas itself immediately forgets shapes once they are drawn.
