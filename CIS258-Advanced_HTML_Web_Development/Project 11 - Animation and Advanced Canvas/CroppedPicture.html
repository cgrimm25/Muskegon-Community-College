Topic 1: Display Part of an Image on a Canvas

Project Overview: I created a canvas that pulls a source image of Charles Darwin from the Img folder and selectively renders only a specific cropped portion of his face. This demonstrates the topic of image slicing by using the overloaded drawImage() method, passing nine distinct arguments to define the source coordinates and the destination placement. While developing this, I learned that keeping the original image tag hidden via CSS ensures the canvas logic can still reference the loaded DOM element without awkwardly displaying the uncropped source image on the page.
