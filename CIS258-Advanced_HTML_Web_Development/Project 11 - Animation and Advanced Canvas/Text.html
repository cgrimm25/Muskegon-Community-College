Topic 2: Drawing 5 Segments of Text

Project Overview: I generated a single canvas that sequentially renders a numbered list of five distinct text segments, each utilizing a different styling technique. This demonstrates the topic by utilizing fillText(), strokeText(), and manipulating the context.font property to adjust families and sizes dynamically. During development, I changed the fourth and fifth segments to experiment with drop shadows, learning that I must explicitly reset the shadow properties back to transparent afterward so they do not accidentally inherit onto the final text string.
