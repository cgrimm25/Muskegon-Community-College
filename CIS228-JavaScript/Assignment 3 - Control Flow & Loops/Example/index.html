Control Flows and Loops in JavaScript

If-Else Statements

Use if-else to make decisions based on conditions.

Switch Statements

Use switch to select one of many code blocks based on a value.

For Loop

Repeats a block of code a specific number of times.

While Loop

Repeats a block of code while a condition is true.

Do-While Loop

Repeats a block of code once, then continues while a condition is true.
